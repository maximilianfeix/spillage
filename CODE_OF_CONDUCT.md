# Code of conduct

spillage follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume the other person means well, and argue about the code and not about the person. Harassment, insults and publishing someone's private information have no place here, in issues, pull requests or discussions.

One rule is specific to this project: never post a real secret, not even a revoked one, and never post someone else's. Masked values and fingerprints are enough to work on any bug.

If someone crosses the line, report it privately through a [security advisory](https://github.com/maximilianfeix/spillage/security/advisories/new) (only the maintainer sees it) and say that it is a conduct report. Reports are read, kept confidential and answered. The maintainer may edit or remove comments, and block accounts that keep at it.
